## Getting started

This module connects an iphone running the smartPTZ app to the bit focus companion app through a dediated API server.

We are producing events using the dev version. It is working well.

To control your iPhone camera using the smartPTZ remote control:

Add smartPTZ Module to your connections.

Add your smartPTZ-ID (provided in the smartPTZ app on your iPhone, Pro License Required).
